# ✦ 별 탐구실 (중2 과학 Ⅷ. 별과 우주 — 1. 별)

| 주소 | 대상 | 내용 |
|---|---|---|
| `…/star-lab/` | 학생 | 반·번호·이름 입장 → 1~3차시 탐구활동, 제출, 질문 게시판 |
| `…/star-lab/teacher.html` | 교사 | 수업 진행용 발표 화면 (비밀번호 `star2026`) |

## 처음 한 번만 설정하기

### 1. 구글 시트 연결 (학생 제출물·게시판 저장소)
1. 구글 드라이브에서 **새 스프레드시트** 만들기 (예: `별 탐구실 기록`)
2. 메뉴 **[확장 프로그램] → [Apps Script]**
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 💾 저장
4. 오른쪽 위 **[배포] → [새 배포]** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **[배포]** → 권한 승인 (‘확인되지 않은 앱’ 경고가 나오면 [고급] → [이동])
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사
7. `index.html`에서 `const API_URL = '';` 줄을 찾아 따옴표 안에 붙여 넣고 저장 (Claude에게 URL을 알려 주면 대신 바꿔 줌)

### 2. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save** → 1~2분 뒤 주소가 생김

## 시트에 쌓이는 내용
- **1차시 탐구 / 2차시 탐구 / 3차시 탐구**: 학생 한 명당 한 줄 (다시 제출하면 최신 내용으로 바뀌고 ‘제출 횟수’가 늘어남)
- **질문 / 답변**: 게시판 글. 실명은 시트에만 기록되고 게시판에는 ‘2-3반 학생’으로 표시
- 부적절한 글: **숨김** 칸 체크 → 게시판에서 사라짐
- 선생님 답변: ‘답변’ 시트 새 줄에 **질문 ID**를 복사해 넣고, **반** 칸에 `교사`, **답변** 칸에 내용 입력 → 게시판에 ‘선생님’으로 표시

## 수정하면?
GitHub 저장소의 파일이 바뀌면 1~2분 안에 같은 주소에 자동 반영됨.

## 참고
- 교사 화면 비밀번호는 가벼운 잠금 장치임 (수업 화면에는 학생 개인정보가 없음)
- 학생 작성 내용은 기기에 자동 저장되지만, 시뮬레이션 측정표는 새로 고침하면 지워지므로 같은 시간에 제출하도록 안내
